# 🛒 GMC RP 新商品申請フォーム

**ゲーム内の店舗を運営するプレイヤーが、新商品をブラウザから申請できる Web アプリ**

※ 現在は運用していません

</div>

GTA5 のロールプレイサーバー「GMC RP」で、店舗を運営しているプレイヤー向けに作った Web アプリです。
店舗オーナーが新商品を簡単に追加できるようにするために作りました。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
少人数の運営で回すために、このフォームのほかに「市民リスト」や「ステッカー申請フォーム」も作りました。

## 主な機能

| 画面 | 使う人 | 内容 |
| --- | --- | --- |
| 📝 **新商品申請** | 店舗オーナー | 商品名、説明、重さ、画像、クラフトのレシピなどを入力して申請 |
| 📋 **申請済み商品一覧** | 店舗オーナー・運営 | 申請した商品を一覧で確認。運営はここで追加・キャンセルを処理 |
| 🧾 **ジョブデータ** | 運営 | 店舗ごとに、追加済みの全商品をゲームに組み込むコードとして表示・コピー |
| 👥 **アカウントリスト** | 運営 | アカウントの権限と、担当する店舗（ジョブ）を管理 |

### 申請できる商品の種類

| 種類 | 内容 |
| --- | --- |
| 通常アイテム | ふつうの商品 |
| 効果アイテム | 食べる・飲むと空腹、渇き、体力、ストレスの値が変わる |
| 画像表示 | 使うと画像が表示される |
| 音楽再生 | 使うと音楽が流れる |
| アイテム付与 | 使うと別のアイテムがもらえる |

## 工夫したところ

### これまででいちばん大きなテーブル設計

申請のときに入力する項目がどうしても多くなるため、これまで作った DB のテーブルの中でいちばん大きなテーブルになりました。
データを取得するときのキャッシュ効率を上げるため、各カラムに `VARCHAR` と `TEXT` のどちらを使うかを慎重に選びました。
その結果、`VARCHAR` を使ってキャッシュ効率を上げ、サーバーの負担を減らせました。

### 素材を探しやすいクラフト設定

ゲーム内のクラフト機能で作る商品は、必要な素材も設定します。
素材を選ぶ欄に文字を入力すると、その文字を含む素材が候補に出てくるので、店舗オーナーは素材を簡単に選べます。

### 運営が確認しやすい一覧

- 申請済み商品一覧にはフィルターがあり、店舗や状態（申請中・追加済み・キャンセル済み）で絞り込めます
- 選んだフィルターはブラウザに保存されるので、次に開いたときもそのまま使えます
- 店舗オーナーには自分の店舗の商品だけが表示されます

### 申請内容をそのままゲーム用のコードに

運営は、申請された商品をゲームに組み込む Lua のコードとして確認できます。
申請済み商品一覧では 1 商品ずつ、ジョブデータのページでは店舗ごとに全商品をまとめて確認・コピーできます。
コードは Prism.js でハイライトして見やすくしています。

### アカウントと権限の管理

アカウントリストで、権限（運営・店舗オーナーなど）と担当する店舗を運営が簡単に管理できるようにしました。

## 技術スタック

| | |
| --- | --- |
| **Frontend** | React 18, React Router, Tailwind CSS, Headless UI, Prism.js |
| **Backend** | Node.js, Express, MySQL, JWT, Multer（画像アップロード） |
| **Infra** | Vercel（フロント）, HTTPS の API サーバー, Vercel Analytics |

```
店舗オーナー ──▶ 新商品申請 ─────────┐
                                      ├─▶ API サーバー（Express, JWT）──▶ MySQL
運営 ──▶ 一覧・ジョブデータ・権限管理 ─┘
                   │
                   └─▶ Lua コードをコピーしてゲームサーバーに反映
```

## ディレクトリ構成

```
.
├── frontend/src/
│   ├── components/
│   │   ├── newitem/        # 新商品申請フォーム
│   │   ├── newitem_list/   # 申請済み商品一覧
│   │   ├── job_data/       # 店舗ごとのゲーム用コード
│   │   └── account_list/   # アカウントと権限の管理
│   └── hooks/              # API、認証、キャッシュ、ページ送りの共通処理
├── backend/                # API サーバー（GMC RP のほかのツールと共通）
└── *.sql                   # テーブル作成・移行用の SQL
```
